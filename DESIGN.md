# Interface design
Current reading state: words before the position use #969d98; the current word has a translucent green background rgba(65, 190, 117, 0.28). These are deliberate exceptions to the monochrome interface. Markdown preserves heading/emphasis hierarchy. Voice scroll uses damped motion; Reduced Motion uses immediate positioning.
Operate mode. A quiet black-and-white writing desk: script editor leads, compact settings rail beside it, persistent transport at bottom. Prompter is pure black with white script, faintly dimmed surrounding text, and restrained controls outside its reading viewport. Native system sans is intentional for an everyday Mac utility, not a marketing display voice. No imagery or decorative cards. Tokens: background #0a0a0a, panel #141414, foreground #f5f5f3, secondary #aaa, divider #333, focus #fff. Controls have 6px radii, 40px minimum height, visible focus rings. Spacing 8/12/16/24/32. Narrow screens stack settings below editor. Respect reduced motion.
